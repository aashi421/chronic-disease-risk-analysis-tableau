# chronic-disease-risk-analysis-tablea
## Project Overview
This project analyzes patterns associated with Heart Disease, Diabetes, and Stroke using healthcare data visualization and Tableau.

## Problem Statement
Chronic diseases create significant healthcare challenges. This project explores how demographic characteristics, clinical indicators, symptoms, and lifestyle behaviors are associated with disease prevalence.

## Objectives
- Analyze chronic disease prevalence.
- Compare disease patterns across age groups and BMI categories.
- Explore associations with blood pressure, cholesterol, and glucose.
- Examine lifestyle factors such as smoking, alcohol consumption, and exercise.
- Develop interactive Tableau dashboards to communicate findings.

## Tools and Technologies
- Tableau Public / Tableau Desktop
- Microsoft Excel or CSV
- GitHub
- Python (optional, for data cleaning)

## Project Workflow
1. Data collection
2. Data understanding and cleaning
3. Exploratory data analysis
4. Tableau visualization
5. Dashboard development
6. Findings and recommendations
